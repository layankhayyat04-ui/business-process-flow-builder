Node Types

Six shapes, every flow covered

●

Start

Entry point for the process. Only one per flow. Bright green — immediately visible.

▭

Process

Any action or task. The most common node — drag several onto the canvas to map a workflow.

◆

Decision

Yes / No branch. Two outgoing ports route the flow based on a condition.

▱

Data

Input / output step. Use when the flow reads from or writes to a system, file, or API.

⏱

Delay

Wait state — approval queue, timer, SLA window. Violet draws the eye to latency points.

●

End

Terminator. Multiple ends are fine for different outcomes (approve, reject, timeout).

// Smooth S-curve from any port to any port
function cubicPath(a, b, aS, bS) {
  const d = 80; // control-point offset px
  let c1x=a.x, c1y=a.y, c2x=b.x, c2y=b.y;

  // Source port pushes its control point outward
  if (aS === 'right')  c1x += d;
  if (aS === 'left')   c1x -= d;
  if (aS === 'bottom') c1y += d;
  if (aS === 'top')    c1y -= d;

  // Target port pulls its control point outward
  if (bS === 'right')  c2x += d;
  if (bS === 'left')   c2x -= d;
  if (bS === 'bottom') c2y += d;
  if (bS === 'top')    c2y -= d;

  return `M${a.x},${a.y} C${c1x},${c1y} ${c2x},${c2y} ${b.x},${b.y}`;
}
